# 自踩壘包符號（A）查證筆記

查證日期：2026-08-20

## 已核對結論

日式／早稻田式守備記錄將野手自行踩壘包的刺殺，以守備位置數字後接壘包字母表示。`A` 代表一壘、`B` 代表二壘、`C` 代表三壘、`H` 代表本壘。例：一壘手接滾地球後自行踩一壘，記作 `3A`；投手傳給補位踩一壘的二壘手，記作 `1-4A`。

此結論已與專案核心規範 `docs/waseda-core-standard.md` 第 96 行的既有 1189LAB 補充規範一致；後續實作需將 `A` 先做為一壘自踩壘包的可選傳接符號，並保留現行守備號碼與 `-` 傳接順序。

1189LAB 的原文進一步指出：壘包字母原則上用於「非原守備位置的球員進入該壘補位」；但一壘手處理一壘滾地並自行踩一壘的 `3A` 也是明確列出的常用範例。因此介面需將 A 說明為「自踩一壘／補位入一壘」，而非將它誤解為一般傳球事件。
