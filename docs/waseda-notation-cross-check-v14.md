# 早稻田式打席格分區核對（V14）

本文件僅保存本輪依公開教學核對的記錄規則，作為單場整體紀錄的顯示與受控補正依據；不改變現場比賽事件、跑壘、統計或正式結算。

## 核對結論

| 分區 | 正確資訊 | 本次採用規則 |
| --- | --- | --- |
| 左側球數欄 | 每一球的壞球、好球、界外、觸擊等逐球符號 | 僅由「逐球修改」依現場紀錄流程編寫。 |
| 外圈／一壘路徑 | 球性、方向／守備位置、打擊結果與守備傳接序列 | 滾地球球性與守備位置分開；傳接以 `6-3`、`3A`、`3-1A` 等序列另列，不覆蓋球性。 |
| 中央菱形內圈 | 出局次序、得分、自責／非自責與殘壘 | 出局必須使用 I–III；得分置於中央，不能把安打或守備傳接置於中央。 |
| 跑壘路徑 | 盜壘、暴投、捕逸、投手犯規、跑壘出局等造成的進壘 | 只由「跑壘紀錄修改」調整其視覺覆蓋，不回寫正式跑壘事件。 |

## 實作判定

紅圈內原 `6-3` 類記號應視為**守備傳接序列**，必須與 GO／FO／LD 等球性使用不同固定位置。`3A` 表示野手自行踩一壘完成出局；`3-1A` 表示傳給補位投手踩一壘。中央 `I` 表示第一個出局，並非打擊結果。後續長按打席將把原「外圈／內圈／其他」入口改為：`全刪除修改`、`內容逐一修改`、`跑壘紀錄修改`；內容逐一修改依現場紀錄順序處理逐球、擊球後球性、方向／守備位置、結果及傳接事件。

## 公開來源

1. [Scorebook App「基本プレー」](https://bbscorer.com/help/score_basic.html)：中央格的 I–III、得分與殘壘；野手守備號 1–9；滾地球、飛球、守備傳接、失誤與進壘記錄。
2. [BASEBALL ONE「野球スコアブックの書き方」](https://baseball-one.com/blog/archives/274598/)：早稻田式打席格方向、中央出局、守備傳接序列（含 `3A`、`3-1A`）、GO／FO 與安打／跑壘記法。

> 註：不同團體可能使用相近但非完全一致的逐球符號。本專案以既有的早稻田符號字典及上述「分區與傳接分離」原則為準，避免把球性、傳接與中央出局／得分混寫。
