# 早稻田個人紀錄欄參考規則

## 來源與採用範圍

本規格以使用者提供的「記錄欄說明」示意圖（`/home/ubuntu/upload/22947.jpg`）為版型的第一優先依據，並交叉核對下列公開教學資料，瀏覽日期為 2026-08-14：

1. [追勵 J.Lead〈棒球記錄 基礎教學-1〉](https://jlead2022.com/archives/229/)
2. [阿衡野趣哪〈棒球記錄法：棒球記錄表紙格式和符號記錄方式〉](https://bimeci.pixnet.net/blog/posts/8171619554)
3. [追勵 J.Lead〈慶應式記錄法〉](https://jlead2022.com/archives/2746/)（僅用於確認早稻田式的球數欄位於左側，以及壘包視角；不可將慶應式符號混入早稻田式）

> 公開教學指出記錄符號可能因聯盟或記錄單位而有慣例差異。本 App 以使用者示意圖與中華職棒／2010 台灣職棒相容寫法為優先，所有符號以結構化欄位保存，保留後續規則微調能力。

## 統一版型：一個格子就是一個個人打席

早稻田個人紀錄欄固定分為**左側球數欄、外圈四分區、中央菱形內圈**。每次打席先記錄逐球，再記錄造成上壘、出局或跑壘推進的外圈過程，最後以內圈標示打席結果、出局序號、失分或殘壘。所有現場、逐局與單場總表的個人打席格皆必須使用同一元件與資料映射。

| 區塊 | 視覺規格 | 資料欄位 | 主要用途 |
| --- | --- | --- | --- |
| 球數欄 | 格子左側窄欄、由上至下逐球累積 | `pitches[]` | 好球、壞球、界外、揮空、觸擊、擦棒與擊出球。 |
| 外圈左上 | 紅字為安打；藍字為跑者出局或野手選擇 | `result`、`hitType`、`runnerEvent`、`fieldingSequence` | `1B / 2B / 3B / HR`、`CS / PO / DP / TP / FC`。 |
| 外圈左下 | 紅色圈選打點 | `rbi` | 以圈選數字 ①–④ 顯示打點。 |
| 外圈右上 | 藍字非安打上壘／特殊事件 | `onBaseEvent`、`specialEvents[]` | `BB / HBP / WP / PB / K` 與不死三振等。 |
| 外圈右下 | 藍字擊球方向與守備傳球序列 | `trajectory`、`fieldingSequence` | 守備位置 1–9、傳球路徑與滾地／平飛／高飛性質。 |
| 菱形邊線 | 紅線表示安打推進；藍線表示非安打推進或盜壘 | `advances[]` | 視覺化打者／跑者依壘包方向的移動。 |
| 內圈菱形 | 中央虛線菱形 | `outsInPlay`、`runs`、`earnedRuns`、`leftOnBase` | 出局 I–III、失分空心圓、自責分實心圓、殘壘草寫 `l`。 |

## 球數欄符號字典

下表按使用者示意圖與追勵教學的名稱建立。畫面呈現優先使用可辨識的 Unicode／線條圖樣；資料層另保存標準化代碼，確保投球九宮格、球數統計、個人格與匯出表一致。

| 標準代碼 | 顯示符號 | 中文說明 | 逐球統計影響 |
| --- | --- | --- | --- |
| `called_strike` | `○` | 沒有揮棒好球 | 好球 +1 |
| `swinging_strike` | `⊖` | 揮棒落空好球 | 好球 +1 |
| `ball` | `—` | 壞球 | 壞球 +1 |
| `foul` | `△` | 界外球 | 未滿兩好球時好球 +1 |
| `foul_tip` | `▲` | 擦棒被捕 | 依結果計入好球／出局 |
| `bunt` | `⌁` | 觸擊球 | 依打席結果 |
| `missed_bunt` | `◓` | 觸擊落空 | 好球 +1 |
| `bunt_foul` | `△⌁` | 觸擊界外 | 未滿兩好球時好球 +1 |
| `foul_error` | `△E` | 界外球野手失誤 | 依裁決；打席持續 |
| `ball_in_play` | `•` | 擊出球（有結果） | 球數 +1，結束或延續打席依結果 |

## 外圈與內圈事件字典

| 事件族群 | 記錄代碼／呈現 | 所屬區域 | 資料連結 |
| --- | --- | --- | --- |
| 安打 | `1B`、`2B`、`3B`、`HR`＋紅色壘線 | 左上、菱形邊線 | 打擊結果、壘包推進、安打／長打統計。 |
| 守備出局 | `6-3`、`6-4-3 DP`、`F8`、`L6`、`T` 等 | 右下與內圈 | 守備序列、出局數、雙殺／三殺統計。 |
| 失誤與野選 | `E6`、`FC` | 左上或右下 | 上壘原因、守備失誤、跑者推進。 |
| 盜壘與跑者出局 | `SB`、`CS`、`PO` | 左上、菱形邊線 | 跑壘事件、被刺／牽制出局與壘包更新。 |
| 非安打上壘 | `BB`、`HBP`、`K`（不死三振） | 右上 | 保送、觸身球、三振與上壘統計。 |
| 投捕特殊事件 | `WP`、`PB`、`BK` | 右上、菱形邊線 | 暴投、捕逸、投手犯規及跑者推進。 |
| 打點 | `①`–`④` 紅色圈選 | 左下 | 打點統計，並與得分跑者關聯。 |
| 出局序號 | `I`、`II`、`III` | 內圈 | 該打席／跑者造成的局內出局順序。 |
| 失分／自責分 | `○`／`●` | 內圈 | 投手失分、自責分與投手統計。 |
| 殘壘 | 草寫 `l` | 內圈 | 局末壘上殘留跑者。 |

## 實作準則

1. **先資料、後圖樣：** 每一個符號必須對應可序列化事件資料，而非只以字串寫入畫面。
2. **單一元件：** 現場目前打者、壘上跑者縮圖、後兩棒預覽、本局打者列與單場整體紀錄，均以同一 `WasedaPersonalRecordCell` 元件衍生不同密度版本。
3. **色彩有語意：** 安打、打點與安打推進為紅色；非安打推進、跑壘／守備／特殊事件為藍色；球數與內圈結果採深灰或黑色。
4. **橫式優先：** 手機橫式以可讀取的完整格優先，平板可顯示更完整的符號說明；縮小版本不得刪除球數欄、菱形與外圈語意。
