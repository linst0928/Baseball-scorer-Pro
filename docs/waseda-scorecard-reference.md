# 早稻田紀錄表實作參考

來源：<https://bimeci.pixnet.net/blog/posts/8171619554>，於 2026-08-13 擷取。

教學將每一個菱形小格定義為球員的一次打席，並分為三個層次：

1. **球數欄**：先記錄投手逐球內容，例如好球、壞球、界外與擦棒球。
2. **外圈格**：記錄打者如何上壘或出局，以及安打方向、擊球類型、守備／傳球處理等打擊或跑壘內容。
3. **內圈格**：記錄本次打席的最終結果、出局序號與壘上跑者的盜壘、推進、殘壘等動態。

記錄順序必須是先由球數欄開始，再以外圈格記錄打者上壘或出局方式，最後以內圈格補足最後結果與跑壘動態。本專案的現場本壘格、右上本次打席格與一／二／三壘跑者格將共用同一批逐球、打擊及跑壘事件，確保與單場整體紀錄同步。
