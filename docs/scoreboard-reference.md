# 主客場比分板參考規格

## 來源

- 使用者附件：`/home/ubuntu/upload/比分呈現.jpg`

## 已確認的版面結構

參考圖使用緊湊的橫向表格：第一欄為球隊名稱，後接逐局欄位 `1` 至正式局數，末端為 `R`（得分）、`H`（安打）、`E`（失誤）。主場及客場各佔一列。表格具有深色邊線、淺色表頭與足夠的數字對比，適合作為橫式 Android／平板上方比分摘要。

## 實作約束

- 初始欄位依每場 `maxInnings` 顯示。
- 比賽進入延長局時，比分板依實際最高局次自動增加欄位。
- 既有比分不會因延長局顯示而截斷；窄螢幕採水平捲動保留所有局數。
- `H` 與 `E` 應由可追溯的打席／失誤紀錄計算，不以未提供的資料推測。
