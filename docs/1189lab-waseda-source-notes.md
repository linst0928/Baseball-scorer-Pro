| 打球種類 | 飛球 `⌒`、平飛 `ー`、滾地 `＿` | 以守備位置數字搭配種類符號；方向以 `・` 補充，作為按鈕與即時預覽一致圖示。 |

| 打席結果 | 四壞 `B`、故意四壞 `IB`／`*B`、觸身 `DB`、三振 `K`、見逃三振 `○K`、振逃以反向 K | 新增／調整可操作按鈕與速查說明時採此標記；已存在的資料代碼可保留相容映射。 |
| 犧牲打 | 犧打以方框包住、犧飛以三角框包住 | 後續新增犧打／犧飛操作時，採框選記法，勿以普通安打或出局符號取代。 |

| 守備傳接 | 補殺－刺殺以 `ー` 連結；偏轉／交接以 `・`；補位用一壘 `A`、二壘 `B`、三壘 `C`、本壘 `H` | 守備預覽和速查表應顯示 `5ー3`、`1・4ー3`、`3A` 等標準樣式。 |

## 稽核結論

1. 既有安打紅線、出局羅馬數字、得分圓點、殘壘、WP／PB／BK 與守備序列資料流可保留。
2. 按鈕與速查表的可見圖示應優先對齊 `⌒`、`ー`、`＿`、`B`、`DB`、`K`、`○K`、`E`、`FC`、`WP`、`PB`、`BK`。
3. `SB` 與 `S` 的視覺表記衝突需依核心規範的衝突提示程序，獲得使用者決定後再替換。
