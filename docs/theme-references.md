# 非原廠主題設計參考

本文件只萃取公開資料中的高層次色彩原則，不重製 LINE、WhatsApp 或 AutoCAD 的品牌介面。

| 參考 | 可採用的原則 | 本專案應用 |
| --- | --- | --- |
| [Nielsen Norman Group：Using Color to Enhance Your Design](https://www.nngroup.com/articles/color-enhance-design/) | 以主色、次色與重點色建立清晰的視覺比例 | 將背景／表面作為主體，隊伍與主操作作為次色，錯誤與警示保留給狀態色 |
| [Material Design：Dark theme](https://m2.material.io/design/color/dark-theme.html) | 深色介面以不同明度表面建立層級，避免以純黑搭配過度飽和色彩 | 深色與灰階模式採暗藍灰／石墨表面、明亮文字及受控的重點色 |
| [Autodesk：Color Theme](https://www.autodesk.com/support/technical/article/caas/tsarticles/ts/1QtnRgAv9FuQ4q0ImJj07x.html) | 專業工作台應維持穩定深色基底與高辨識操作色 | 工作台模式以低干擾背景、清楚邊框及高辨識按鈕支援長時間記錄 |
| [WhatsApp dark mode 色彩彙整](https://themeandcolor.com/blog/whatsapp-dark-mode-colors) | 深綠與深藍灰的低對比表面適合作為訊息／資料密集介面背景 | 鮮豔模式使用深靛藍基底與薄荷綠動作色，但不使用其原始品牌配置 |

## 設計約束

- 所有模式必須提供背景、表面、文字、次要文字、邊框、主要／次要按鈕與成功、警告、錯誤狀態色。
- 可讀文字與背景必須保持足以支援橫式球賽記錄的高對比；色彩不得作為唯一訊息載體。
- 「原廠配色」不在本輪調整範圍；其餘模式採獨立色彩語言，而非只替換單一主色。
