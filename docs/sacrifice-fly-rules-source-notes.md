# 高飛犧牲打規則來源筆記

## 本輪採用規則

高飛犧牲打（SF）適用於打者擊出外野或界外區的高飛出局球，並使跑者得分。此結果需要將打者記為一個出局、計入因此得分的打點，卻不可計入打數或安打。快捷操作只在存在可得分跑者時顯示為可用，並在送出前明示將記錄的得分與打點。

### 實作邊界

| 項目 | 系統處理 |
|---|---|
| 打席結果 | `SF`，保留高飛球與守備傳接資訊 |
| 出局數 | 打者出局，既有局數／半局結束規則照常套用 |
| 跑者 | 三壘跑者得分；其他跑者維持既有安全推進規則 |
| 統計 | `PA +1`、`SF +1`、`RBI + 得分跑者數`；`AB`、`H` 均不增加 |
| 早稻田顯示 | 於同一打席內保留高飛球和跑者得分／進壘表記 |

## 來源

1. [MLB Glossary — Sacrifice Fly](https://www.mlb.com/glossary/standard-stats/sacrifice-fly)：說明高飛出局球使跑者得分時，打者獲得打點，且高飛犧牲打不計入打數。
