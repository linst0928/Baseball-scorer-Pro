# V13 單場整體紀錄：參考版面與安全編輯規則

本文件只保存使用者於 2026-08-25 提供的兩張參考圖所指定的**版型與互動需求**；不將圖片內的比賽資料、球員姓名、比分或既有賽事結論匯入 App。

## 2013 WBC 左側列式名單

1. 左側採連續的表格欄列，而非一個先發卡片後再出現大面積候補空白區。
2. 每位已登場或候補保留的人員都要佔一條明確、同高度的列；固定欄依序呈現守備位置、先攻打擊姓名、背號、棒次／候補標示。
3. 換人後的人員列從發生局數開始承接該棒次，但不同棒次的換人時間可自然錯位。
4. 未登場的候補格是視覺保留列，不得製造打席、跑壘或守備事件。

## 符號位置

1. 滾地球（GO）須以既有早稻田球性／方向符號呈現於打席外圈，不得被誤呈現為高飛球或置入菱形中央。
2. 傳球／守備傳接序列（例如 `6-3`、`4-6-3 DP`、`E5-3`）屬外圈守備傳接資訊，與球性／方向分開，並置於可辨識的外圈守備傳接位置。
3. 菱形中央只保留得分、出局順序、殘壘、CS 或不死三振等內圈語意；不以安打、滾地球或傳接文字覆寫。

## 場次選擇與長按編輯

1. 單場整體紀錄上方提供「現場／全部」篩選、日期與盃賽篩選，並可選取一場比賽作為目前工作台場次。
2. 長按守備格：開啟守備位置選擇；長按姓名或背號格：只從該隊球員名單選取人員；長按完成打席格：直接進入既有打席補正流程。
3. 所有長按流程均須有取消／上一步；打席補正仍維持半局結束或 final 的安全鎖與確認前預覽。
4. 名單／守備的快速調整僅建立整體紀錄表的視覺覆蓋，不回寫正式先發名單、換人紀錄、逐球、比分、跑壘或統計。
