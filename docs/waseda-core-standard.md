# 早稻田式紀錄法：應用程式核心規範

> **效力範圍。** 本文件以使用者指定的〈[一分钟看懂棒球记录表](https://zhuanlan.zhihu.com/p/538172811)〉為本專案的最高紀錄呈現規範。所有資料模型、圖示、視覺紀錄、說明文字與後續需求皆不得違反本規範；若需求與此文件衝突，必須先向使用者說明差異並取得確認。

## 1. 紀錄欄結構與記錄順序

每一個菱形小格代表一個打席，由三個不可混用的區域組成：**球數欄**、**外圈格**與**內圈菱形格**。記錄順序固定為：先在球數欄逐球記錄，再於外圈格畫記打擊、上壘、出局與跑壘過程，最後以內圈格寫下該打席的最終結果。

| 區域 | 核心用途 | 禁止混用的資訊 |
| --- | --- | --- |
| 球數欄 | 投手對此打者的每一顆投球與換投中斷 | 打擊最終結果、跑壘推進線 |
| 外圈格 | 擊球性質與方向、守備傳接／失誤、上壘／出局過程、各壘推進線 | 僅屬最後結果的出局順序或得分標記 |
| 內圈菱形格 | 此打席最後結果、出局順序、得分、打點，以及壘上跑者之後的動態 | 逐球球數與完整擊球過程 |

## 2. 擊球、守備與上壘原則

外圈是縮小的內野。外圈的四個方向對應壘包，兩壘間的區域畫記通往該壘的事件。擊出球性質以高飛、平飛、滾地的符號搭配守備位置數字表達；守備傳接依實際順序書寫，失誤以 `E` 接在失誤守備員或傳接序列後。紅線的延伸壘數表達擊跑員依安打實際前進的壘數。

| 情境 | 應呈現的位置與原則 |
| --- | --- |
| 安打 | 外圈畫紅色推進線至實際到達壘包；可加球性、方向、守備位置與安打結果 |
| 保送 | 外圈記 `B` 或 `BB`，並畫本壘至一壘的上壘動線 |
| 觸身球 | 外圈記 `HBP` 或 `D`，並畫本壘至一壘的上壘動線 |
| 失誤上壘 | 外圈依擊球／傳接方向加 `E` 與守備員代號，再畫實際前進動線 |
| 出局 | 外圈記擊球及守備過程；內圈記錄第幾個出局數 |
| 全壘打與得分 | 外圈走完全壘路徑；內圈以大紅點表示擊跑員得分，左下小圈數字表打點 |

## 3. 跑壘與局結束原則

跑壘員在後續打席的盜壘、推進、失誤推進、暴投或捕逸，必須回寫至其**來源打席的內圈**，保留該跑者完整路徑。盜壘需標註 `SB`；盜壘失敗記 `CS`。三出局、攻守交換時仍留在壘上的跑者，應在其來源打席內圈標記草寫小寫 `l`，作為 `LOB`（殘壘）。

## 4. 例外與中斷處理

| 情境 | 規範 |
| --- | --- |
| 不死三振 | 第三好球捕手漏接後，只有一壘空或兩出局時才可合法跑一壘；安全上壘以倒寫 `K` 表達，並保留球數欄的三振球序。 |
| 換投 | 新投手面對的第一位打者，在其打席格加 `︺` 並附投手姓名／背號；若打席尚未結束即換投，符號置於球數欄。 |
| 代打／代跑／換守 | 必須保留事件時點與新舊球員連結，不可覆寫已完成打席或壘包來源紀錄。 |

## 5. 本專案對齊要求

1. 所有個人紀錄欄、現場紀錄壘包、單場整體紀錄與符號速查表必須以此三區職責呈現。
2. 資料模型必須可區分投球序列、外圈過程、內圈最終結果，以及來源打席的跑壘後續事件。
3. 顏色僅為輔助辨識，不能取代符號、線段方向與記錄位置；任何既有自訂顏色規則若與本文記錄位置衝突，須以本文優先。
4. 後續需求若要求與上述規則相反的記錄位置、符號意義或跑壘來源，介面須先提示「與早稻田核心規範衝突」，說明差異並等待使用者確認。

### A. 打擊紀錄的組合式符號

1189LAB 的打擊頁明確將每個擊球結果拆為三個資訊：**守備員位置數字＋打球種類＋方向**。按鈕與即時預覽應以此順序組合，讓相同的飛球、平飛球或滾地球能保留方向差異；打球種類採 `⌒`（高飛球）、`－`（平飛球）、`＿`（滾地球），方向以 `・` 表示。安打與凡打皆須在外圈表達打向哪個守備方向；一壘出局等傳接球結果則按實際守備序列書寫，例如 `5-3`。 [4]

| 情境 | 已納入的按鈕／紀錄對齊規則 |
| --- | --- |
| 高飛球 | 以 `⌒` 搭配守備位置，如左外野高飛球為 `⌒7`；界外飛球加 `F`。 |
| 平飛球 | 以 `－` 搭配守備位置與方向。 |
| 滾地球 | 以 `＿` 搭配守備位置與方向。 |
| 守備傳接 | 以捕殺至刺殺的實際順序書寫，如三壘手傳一壘為 `5-3`。 |
| 安打 | 維持本專案已確認的紅色壘線：1B 右下、2B 再加右上、3B 再加左上、HR 全菱形；紅色僅為輔助，符號與壘線仍為必要資訊。 |
| 特殊安打 | 內野安打以圈選／外框表示；犧牲觸擊安打採 `B.H.`。 |

### B. 基本記錄、方位與最終狀態

1189LAB 的基本頁確認：打席格以菱形模擬球場，依右手方向逆時針為**一壘、二壘、三壘、本壘**；每格同時承載一名打者的一個打席、逐球、打擊、跑壘與守備結果。此方向與本專案現場壘包工作台已固定的「本壘下、一壘右、二壘上、三壘左」一致。出局以羅馬數字 `I`、`II`、`III`，殘壘以草寫 `l`；三出局攻守交換應於最後打者格標記 `//`。 [5]

| 主題 | 已納入的統一規則 |
| --- | --- |
| 守備位置 | `1` 投手、`2` 捕手、`3` 一壘、`4` 二壘、`5` 三壘、`6` 游擊、`7` 左外、`8` 中外、`9` 右外。按鈕位置數字與符號速查表均沿用此序。 |
| 出局與殘壘 | 內圈保留 `I`／`II`／`III` 的出局順序、`l` 的殘壘，以及 `//` 的半局結束記號；此規則補強既有 LOB 回寫，不能以顏色取代。 |
| 得分責任 | 非投手自責失分以 `○`，投手自責失分以 `●`；此符號應與內圈得分呈現及投手統計責任資料一致。 |
| 賽事資訊 | 日期、賽事／輪次、場地、先後攻隊、開始／結束時間、天候、風向與場地狀況皆為比賽紀錄基本資料；既有賽事建立與天氣欄位必須保留。 |
| 球員交代 | 交代須保存發生時點及新舊球員關聯；投手交代應可辨識發生於哪一球，以維持球數可追溯性。 |

5. 〈[野球スコアの読み書き　-スコアブックの基本を知ろう-](https://1189lab.net/score_basic/)〉，1189LAB，於 2026-08-15 查閱。

### C. 守備傳接球與特殊守備記法

1189LAB 的守備頁明確以守備者號碼及球的實際傳遞順序表示守備。補殺與刺殺以連字號 `-` 連結；同一球被偏轉後由另一位野手處理，以中點 `・` 連結。每一位實際碰觸球、參與連線的野手均應出現在序列中。 [6]

| 類型 | 統一符號／按鈕預覽規則 |
| --- | --- |
| 一般傳接球 | 以 `-` 表示傳球順序及補殺—刺殺，例如 `6-4-3`。現場的傳接球序列編輯器、FO／GO 預覽與單場紀錄必須一致。 |
| 併殺／三殺 | 多名打者的結果以括號狀連結並標記 `DP`／`TP`；按鈕應保留 `DP`、`TP` 這一標準縮寫。 |
| 野手自踩壘包 | 一壘 `A`、二壘 `B`、三壘 `C`、本壘 `H`。例如一壘手自行踩一壘為 `3A`；補位入壘時於守備號碼後接壘包字母，例如 `1-4A`。 |
| 偏轉與補位 | 球被第一位野手碰到後由他人處理時以 `・` 串連，例如 `1・4-3`；不可誤寫為一般順序傳球。 |
| 夾殺／夾擊 | 所有涉及野手以 `・` 串連，最後一次傳球以 `-` 相連；途中發生失誤時加 `E`。 |

6. 〈[野球スコアの読み書き　-守備のスコアの読み方・つけ方-](https://1189lab.net/score_fielding/)〉，1189LAB，於 2026-08-15 查閱。

### D. 跑壘、得分與觸殺記法

1189LAB 將跑壘視為「出壘後，跑者因打者結果、投手或守備方行為所產生的結果」。進壘必須標明是因哪一位打者／哪個打席發生；單純進壘以括號中的打序數字，造成該打者打點的進壘以圈號打序數字表記。 [7]

| 類型 | 統一符號／按鈕預覽規則 |
| --- | --- |
| 單壘進壘 | 沿正確壘線推進，並在到達壘格附註引起進壘的打席資訊；現有 `ADV`、`WP`、`PB`、`BK` 按鈕需保留原因名稱與來源打席。 |
| 多壘推進 | 以連續壘線連結起點與終點；例如一壘至三壘需連結一壘—二壘—三壘。圖形可視化須遵守既有「安打紅線優先、一般跑壘藍線」規則。 |
| 得分與打點 | 跑者回本壘時標記得分；若該打席計入 RBI，來源打者的打點資訊與跑者終點需同步。 |
| 觸殺／跑壘刺 | 以反向箭頭連至刺殺壘格，並標示守備傳接序列（如 `9-5`）；需要時可加 `TO`。現有 `CS` 選擇視窗必須先選跑者與目標壘包，再回寫來源打席與出局數。 |
| 傳球空檔進壘 | 因守備傳球間隙進壘時，守備的補殺—刺殺序列應置於括號中，以與一般進壘原因區隔。 |

7. 〈[野球スコアの読み書き　-走塁スコアの読み方・つけ方-](https://1189lab.net/score_running/)〉，1189LAB，於 2026-08-15 查閱。
