# 球隊識別與主客場配色

本次功能以 `Team.logoUri` 保存已方形裁切並壓縮的隊徽 URI，並以 `Team.customColor` 保存使用者確認的球隊主題色。兩欄位皆為選填，以維持舊有本機資料、雲端資料與既有賽事快照的相容性。

首頁的守備配置卡必須繼續只引用 `HOME_DEFENSE_FIELD_IMAGE`。已指派的守備標記採短按開啟球員資訊，長按才執行指派，避免短按誤改守位。彈窗以橫向資訊列顯示背號、姓名、守位、打投慣用手與棒次，不擴張首頁工作區高度。

跨分頁隊名應統一使用緊湊隊徽名稱元件；隊徽尺寸須限制在文字行高內，絕不可增加任何工作台面板高度。現場紀錄與單場整體紀錄的背景色應以低透明度方式套用，並在沒有自訂色時分別維持主隊暖色、客隊冷色的既有語意。
