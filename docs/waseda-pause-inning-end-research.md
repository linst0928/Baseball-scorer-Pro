# 早稻田紀錄法：暫停與局末符號研究筆記

## 使用者提供圖片的符號

| 情境 | 圖中符號 | 預定 App 語意 |
| --- | --- | --- |
| 攻方暫停 | `O.C` | 純記錄事件；不變更球數、出局數、壘包或打席統計。 |
| 守方暫停 | 圈選 `T` 向右箭頭 | 純記錄事件；不變更球數、出局數、壘包或打席統計。 |
| 每局攻擊結束 | `//` | 僅於半局正常結束時標示，且不自行改變出局數。 |
| 未滿三人出局結束比賽 | `///` | 僅於裁定、提前結束或其他規則允許的賽事結束情境使用；需要使用者確認理由，不得拿來取代一般半局結束。 |

## 已核對來源

Sports Vision 的中華職棒記錄表教學明確說明：每一個半局結束，應於記錄格右下角畫上兩條斜線，作為該半局結束標記。此做法支持圖片中 `//` 的局末語意。[1]

知乎的早稻田式記錄法教學在此環境受到頁面限制而未能讀取完整內容，因此不以其作為具體符號實作的唯一依據。後續會以使用者提供圖片的符號圖例、既有專案早稻田規則與可讀來源共同驗證。

## 實作限制

1. 暫停事件僅加入符號時間線與目前打席／局面旁的註記，絕不建立打擊結果、跑壘推進或出局事件。
2. `//` 只能在系統已完成正常半局時自動／手動確認；若出局數少於三，必須改走賽事結束確認流程，不可誤記為正常結束。
3. `///` 需要顯示「未滿三出局結束本場比賽」確認視窗，並保留原因（提前結束、時間到、裁定等）於賽事備註與紀錄事件。

## 補充規則核對

日本高野連的規則說明將攻方傳令、守方暫停分別視為受規範的暫停次數，顯示兩者是比賽管理事件，而非打擊、跑壘或出局結果。[2] 因此 App 會把圖片中的 `O.C` 與 `T` 記錄為獨立的「比賽註記」事件，明確排除於 PA、AB、球數、出局與壘包狀態的運算。
