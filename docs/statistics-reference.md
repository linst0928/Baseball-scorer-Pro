# 打者與投手統計實作參考

本檔整理使用者指定的兩篇棒球記錄教學，供統計預覽的欄位、中文小字說明與計算驗證使用。

## 打者

| 縮寫 | 中文名稱 | 說明／計算 |
| --- | --- | --- |
| G | 場次 | 出賽比賽的次數。 |
| AB | 打數 | 完成打擊的次數；保送、觸身球與犧牲打不計入。 |
| R | 得分 | 跑者回到本壘所得的分數。 |
| H | 安打 | 安打總數。 |
| 2B／3B／HR | 二壘安打／三壘安打／全壘打 | 各類長打次數。 |
| RBI | 打點 | 打者靠打擊能力打回的分數。 |
| BB／SO | 四壞／被三振 | 保送次數與打者出局的三振次數。 |
| SB／CS | 盜壘／盜壘刺 | 成功盜壘與盜壘失敗。 |
| HBP | 觸身球 | 被投球擊中而上壘。 |
| TB | 壘打數 | 一壘安打 + 二壘安打×2 + 三壘安打×3 + 全壘打×4。 |
| AVG | 打擊率 | H／AB。 |
| OBP | 上壘率 | （H + BB + HBP）／（AB + BB + HBP + 犧牲飛球）；目前資料模型尚未區分犧牲飛球時，於介面標註採可得事件計算。 |
| SLG | 長打率 | TB／AB。 |
| OPS | 整體攻擊指數 | OBP + SLG。 |

## 投手

| 縮寫 | 中文名稱 | 說明／計算 |
| --- | --- | --- |
| W／L | 勝投／敗投 | 依比賽勝敗責任指定。 |
| G／GS | 出賽／先發 | 登板次數與先發登板次數。 |
| SV／SVO | 救援成功／救援機會 | 領先登板並守下勝利的成功與機會。 |
| IP | 投球局數 | 每一個出局為 1/3 局。 |
| H／R／ER／HR | 被安打／失分／自責分／被全壘打 | 投手所失的各類攻擊結果。 |
| BB／SO | 四壞／三振 | 投手投出的保送與三振。 |
| ERA | 防禦率 | （ER／IP）×9。 |
| AVG | 被打擊率 | H／面對打數。 |
| WHIP | 被上壘率 | （H + BB）／IP。 |
| P／STR% | 投球數／好球率 | 逐球紀錄累積的總投球數，以及好球占有效投球比例。 |
