# 單場整體紀錄表核對筆記

## 使用者確認的版型方向

- 以使用者提供的空白單場整體紀錄表作為欄位骨架：上方賽事資料與逐局比分、左側先發／守備、中央逐局打席菱形、下方投手與守備彙總。
- 以使用者提供的完成表作為資訊密度目標：打席符號、跑壘、傳接球、換人、投手與守備摘要可追溯，但數位介面不模擬手寫筆跡。
- 主、客隊維持分隊兩張紀錄表，並共用逐局比分總覽。
- 新手教學採五步：結果、跑者、出局、得分、半局核對。
- 換投、代跑、代打、換守、雙殺、三殺使用逐步確認卡；每一步可返回，落帳後提供復原上一筆與影響摘要。

## 已核對的紀錄原則

| 項目 | 實作原則 |
|---|---|
| 雙殺／三殺 | 維持傳接序列與 DP／TP 結果；實際出局數仍由已確認打席寫入，不能只靠文字符號推算。 |
| 換人 | 保存局數、上下半局、隊別、退場者、進場者、角色／守位與時間；記錄表以銜接列顯示。 |
| 暫停 | O.C／T 為統計中性註記；原因文字只作可追溯備註，不能改變比分、壘包、出局或投打統計。 |
| 局末 | 三出局後才寫入 //；未滿三出局結束比賽才寫入 ///。 |
